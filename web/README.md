# Browser-Prototyp

Ein bewusst einfacher erster visueller Prototyp für das digitale Papiertheater.

Start im Repository:

```bash
python -m http.server 8000
```

Dann im Browser `http://localhost:8000/web/` öffnen.

Der Prototyp verwendet direkt die Hintergründe und Figuren aus `assets/`.
Noch keine KI- oder TTS-Anbindung: zuerst testen wir Bühne, Größen und Positionen.
